# 慧研国际教育官网

本仓库是慧研国际教育官网项目，当前公开网站只服务慧研国际教育品牌展示、服务介绍与咨询转化。

## 项目定位

- 中文为主，英文为辅。
- 品牌定位为英国本地硕博导师团队、非流水线留学、全周期陪伴。
- 网站风格为深蓝、白色、金色点缀，高端、克制、专业。

## 公开页面

- `/`
- `/about`
- `/services`
- `/pathways`
- `/partnership`
- `/contact`

## 内容边界

- 禁止使用“保录取”“100% offer”“guaranteed admission”等夸大话术。
- 禁止虚构合作大学、学生案例、offer 数量。
- 不添加数据库、登录、后台、CRM、CMS，除非明确要求。
- 不修改 `vendor` 目录。

## 常用命令

```bash
npm run dev
npm run build
```
